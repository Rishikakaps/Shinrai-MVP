Noto Sans JP from the official Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/notosansjp

The upstream NotoSansJP[wght].ttf was instantiated at wght=400 using
fontTools 4.67.0 varLib.instancer. This static regular-weight instance is
bundled so Japanese source transcripts remain visible in PDF exports
without reader-installed fonts. FontTools is not a runtime dependency.
